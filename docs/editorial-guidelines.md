# 記事制作・公開の編集ガイドライン（参照入口）

記事は女子中学生にも読める一般向けの文体で、簡潔に説明します。技術者向けの別記事は作成しません。記事執筆ルールは、既存の解説の流れを継承するため、リポジトリ直下の次の文書へ整理しました。このパスは既存の参照を壊さないために残します。

| 文書 | 役割 |
| --- | --- |
| [AGENTS.md](../AGENTS.md) | Codexの作業・公開ルールと必読文書 |
| [EDITORIAL_GUIDE.md](../EDITORIAL_GUIDE.md) | 一般向けの簡潔な文体、視点、構成、レビューの正本 |
| [ARTICLE_TEMPLATES.md](../ARTICLE_TEMPLATES.md) | 一般向けの事件・障害／用語等のひな形 |
| [FACT_CHECK_POLICY.md](../FACT_CHECK_POLICY.md) | 情報源、出典、日付、検証、事実確認の正本 |

本文を書く前に上記を読み、[記事作成の運用手順](article-workflow.md)でFront Matter・分類・表示確認とPRの手順を確認します。ここに独立した執筆ルールを複製しません。

記事の執筆や文書整備の依頼は、本番公開・再公開の承認ではありません。
